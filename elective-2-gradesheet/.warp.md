# Elective-2 Gradesheet - Project Documentation

## Overview
This is an ASP.NET Core MVC application for managing student grades and bulk processing of GitHub repository submissions. The application supports both SQLite and SQL Server databases and includes automated repository analysis and rubric-based grading.

## Architecture
- **Framework**: ASP.NET Core 8.0 MVC
- **Database**: SQLite (default) / SQL Server (configurable)
- **Pattern**: MVC with Service Layer
- **Frontend**: Bootstrap 5, minimal JavaScript (vanilla JS, no heavy frameworks)

## Key Features

### 1. Student Management
- Student profiles and grade tracking
- Section-based organization
- Activity template management

### 2. Bulk Repository Grading
- **MVC-style implementation** (server-side focused)
- GitHub repository cloning and analysis
- Automated rubric-based scoring
- Progress tracking and approval workflows
- Repository URL validation and storage

### 3. Database Support
- Dual database support (SQLite/SQL Server)
- Service layer abstraction (`IGradeService`)
- `GradeDbLiteService` for SQLite
- `GradeDbService` for SQL Server

## Bulk Grading Workflow

### User Flow (MVC Pattern)
1. **Select Section** → Server reloads page with available activities
2. **Select Activity** → Server validates rubric and loads students
3. **Enter Repository URLs** → Client-side validation for GitHub URLs
4. **Submit Form** → Server processes, validates, and starts bulk grading
5. **View Results** → Server redirects with success/error messages

### Technical Flow
1. **Form Submission**: `ProcessBulkGrading` POST action
2. **URL Storage**: `SaveRepositoryUrlsAsync` saves URLs to database
3. **Background Processing**: `StartBulkProcessingAsync` initiates analysis
4. **Repository Analysis**:
   - Clone repositories via `GitService`
   - Scan files via `RepositoryService`
   - Score against rubric via `RubricScoringService`
5. **Results**: Preview, approval, and database updates

## Code Organization

### Controllers
- `HomeController`: Main application logic, bulk grading
- `ActivityTemplateController`: Activity template management

### Services
- `IGradeService`: Main service interface
- `GradeDbLiteService` / `GradeDbService`: Database implementations
- `GitService`: GitHub repository operations
- `RepositoryService`: Repository cloning and scanning
- `RubricScoringService`: Automated code analysis and scoring

### Models
- `BulkGradingViewModel`: View data for bulk grading page
- `BulkGradingFormModel`: Form submission model (MVC pattern)
- `BulkGradingStudentViewModel`: Individual student data
- Shared models for rubric items, file content, scoring results

### Views
- `BulkGrading.cshtml`: Main bulk grading interface
- Server-side rendering with minimal JavaScript
- Form-based interactions following MVC patterns

## Development Principles

### 1. MVC-First Approach
- Server-side form processing over AJAX
- Progressive enhancement with minimal JavaScript
- Proper model binding and validation

### 2. Service Layer Pattern
- Business logic abstracted from controllers
- Database-agnostic service interfaces
- Dependency injection throughout

### 3. Minimal JavaScript
- Vanilla JavaScript only (no jQuery dependencies removed)
- Client-side validation for UX enhancement
- Server-side validation for security and reliability

### 4. Code Quality
- Consistent naming conventions
- Proper error handling and logging
- Performance optimizations (avoid duplicate selectors)

## Configuration

### Database Setup
```csharp
// SQLite (default)
services.AddScoped<IGradeService, GradeDbLiteService>();

// SQL Server
services.AddScoped<IGradeService, GradeDbService>();
```

### Required Services
```csharp
services.AddScoped<RepositoryService>();
services.AddScoped<RubricScoringService>();
services.AddScoped<IGitService, GitService>();
```

## API Endpoints

### GET /Home/BulkGrading
- Main bulk grading page
- Parameters: `sectionId`, `activityTemplateId`, `showNonZeroGrades`
- Server-side form rendering

### POST /Home/ProcessBulkGrading
- Process selected students for bulk grading
- Model: `BulkGradingFormModel`
- Returns: Redirect with success/error messages

### GET /Home/GetActivityTemplates
- AJAX endpoint for activity templates by section
- Used by JavaScript for progressive form enhancement
